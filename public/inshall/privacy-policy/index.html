Privacy Policy

Curio by Inshall · effective 26 November 2026

In short: Curio is a personal app used only by its developer, Inshall. It reads my own data from services I connect, keeps it in my own storage, and never sells, rents, shares it for advertising, or uses it to track anyone.

1. Who is responsible

Curio is made and run by Inshall, an individual developer in Karachi, Pakistan (“I”, “me”). Curio is a personal, non-commercial project. It has no other users: the web version allows sign-in for a single Google account, the owner's. Contact: https://github.com/InshallAdnan.

2. What Curio is for

Curio is a personal inspiration library. It gathers what I save on other services into one place so I can find, sort and use it, next to my own notes, tasks, documents, calendar and finance.

3. What data Curio handles

DataFromWhy
Name, email address, profile pictureGoogle Sign-In (Curio Web)Only to check that the person signing in is the owner.
My YouTube playlists and the videos in them (titles, thumbnails, channel names, links, dates added)YouTube Data API, with my permissionTo show and play my saved videos; later, to let me organize my own playlists.

Curio does not use cookies for advertising or analytics. Curio Web uses one sign-in cookie so I stay signed in.

4. Where the data is stored

5. Who else sees data

  • No one buys or receives it. Data is never sold, rented, or shared for advertising or marketing.
  • AI features, only when I use them: when I ask Curio's AI something, the question and the few items it needs are sent to the AI service I picked (OpenAI / ChatGPT, Google Gemini or Anthropic Claude). AI models that run on my own computer send nothing out. YouTube and Pinterest data is not used to train any AI model.
  • Reminders: the text of a reminder passes through my browser's push service to reach my phone.
  • Data is shared only if the law requires it.

6. YouTube

Curio uses YouTube API Services. By using Curio's YouTube features you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

  • Curio asks for access to my own YouTube account only, and only uses it to read and (in the future) organize my own playlists.
  • Curio keeps the YouTube data it reads up to date when it syncs, and does not keep it for any other purpose.
  • Access can be removed at any time in the Google security settings. After that, Curio can no longer read YouTube data, and its saved YouTube token is removed when I disconnect in Curio.

7. Pinterest

Curio uses the Pinterest API under the Pinterest Developer Terms and Developer Guidelines. It reads only my own boards and pins, and in the future will only change my own boards and pins, when I press a button. It never posts, follows, comments, or reads other people's private data. Access can be removed at any time in Pinterest › Settings › Security and logins › Apps.

8. Keeping data safe

  • All connections use HTTPS.
  • Tokens and keys are stored in Windows Credential Manager on my computer, or as encrypted environment settings on Vercel.
  • Curio Web only lets the owner's Google account sign in.

9. Keeping and deleting data

Data stays as long as I keep it in Curio. I can delete any item, disconnect any service, or remove everything at any time: the desktop data by deleting its folder, the web data by deleting the Turso database. When I disconnect YouTube or Pinterest, Curio stops reading from it and removes its access token; data already copied can be deleted on request within 30 days.

10. Children

Curio is not meant for children and is not used by anyone under 18.

11. Changes

When this policy changes, the new version is posted on this page with a new date. Planned changes (such as Cloudflare R2 storage) will be added here before they start.
